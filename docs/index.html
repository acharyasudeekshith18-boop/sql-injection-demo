        Demo

        Python 3.10+, standard library only. From the project folder:

        $ python3 -m sqli_demo demo
        Vulnerable login: ACCEPTED as admin
Parameterized login: DENIED

        Tests

        Seven unit tests cover normal, wrong-password and injection cases for both paths.

        $ python3 -m unittest discover -s tests -v
        Ran 7 tests … OK
