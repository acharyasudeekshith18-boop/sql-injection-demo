    Why they behave differently
    
    
      
      
    • Vulnerable: the login glues your text into the SQL. A ' in your input ends the quoted value early, so whatever follows is read as SQL code. OR 1=1 makes every row match, and -- turns the rest of the line, including the password check, into a comment.
      • 
      
    • Parameterized: the SQL is fixed, with ? placeholders. SQLite receives your text separately as plain values, so a quote is just a character in a username and the password is always checked.
      • 
      
    • This lab keeps passwords as plain text only to keep the SQL easy to read. Real apps also need proper password hashing.
      •
